# Incident Investigation

## Overview

This section contains the incident investigation process used in this project.

The investigation was performed using Windows Event Logs, Sysmon logs, and SPL queries in Splunk to understand suspicious activities.

---

# Purpose

The main purpose of incident investigation is to:

* Identify suspicious activities
* Analyze security events
* Find the root cause
* Build an event timeline
* Support incident response

---

# Investigation Process

The following steps were performed during the investigation:

1. Detect the suspicious activity.
2. Collect related logs.
3. Analyze the events using SPL queries.
4. Identify Indicators of Compromise (IOCs).
5. Create an event timeline.
6. Determine the root cause.

---

# Investigation Sources

The investigation used the following log sources:

* Windows Security Logs
* Sysmon Logs
* Process Creation Events
* Authentication Events
* Network Events

---

# Result

The investigation helped identify suspicious activities, understand how the incident occurred, and improve security analysis skills using Splunk.
