# MITRE ATT&CK Mapping

## Overview

This section contains the MITRE ATT&CK mapping used in this project.

The detections created in Splunk were mapped to MITRE ATT&CK techniques to understand how different attacker activities relate to real-world attack behaviors.

---

# Purpose

The main purpose of MITRE ATT&CK mapping is to:

* Understand attacker techniques
* Map detections to MITRE ATT&CK
* Improve threat analysis
* Support incident investigation

---

# Mapped Techniques

The following techniques were mapped in this project:

* PowerShell
* Command and Scripting Interpreter
* Command Execution
* Signed Binary Proxy Execution
* Discovery

---

# Mapping Process

The mapping process included:

1. Identify suspicious activity.
2. Find the related SPL query.
3. Match the activity with the MITRE ATT&CK technique.
4. Document the mapping.

---

# Tools Used

* Splunk Enterprise
* Windows Event Logs
* Sysmon
* MITRE ATT&CK Framework

---

# Result

The MITRE ATT&CK mapping helped me understand how attacker techniques can be detected and investigated using Splunk. It also improved my knowledge of threat detection and security analysis.
