# Security Dashboards

## Overview

This section contains the security dashboards created in Splunk.

The dashboards provide a simple and organized view of security events, making it easier to monitor and investigate system activity.

---

# Purpose

The main purpose of these dashboards is to:

* Monitor security events
* Visualize log data
* Identify suspicious activities
* Track system activity
* Support security investigations

---

# Dashboards Included

The following dashboards were created in this project:

* Authentication Dashboard
* Malware Activity Dashboard
* Network Monitoring Dashboard

---

# Dashboard Features

The dashboards display information such as:

* Successful Login Events
* Failed Login Events
* PowerShell Activity
* CMD Activity
* Suspicious Processes
* Network Connections
* Top Source IP Addresses
* Top Destination IP Addresses
* Most Active Users
* Event Trends

---

# Tools Used

* Splunk Enterprise
* Windows Event Logs
* Sysmon
* SPL Queries

---

# Result

These dashboards made it easier to monitor system activity, detect suspicious events, and investigate security incidents using Splunk.
