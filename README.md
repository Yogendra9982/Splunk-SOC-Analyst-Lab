
# Splunk SOC Analyst Lab

## About

This is my Splunk SOC Analyst Lab project.

I created this project to learn how a SOC Analyst works in a real environment. In this lab, I collected logs, searched events using SPL queries, detected suspicious activities, investigated alerts, and created security dashboards.

This project helped me improve my Splunk and log analysis skills.

---

# Tools Used

* Splunk Enterprise
* Windows 10
* Kali Linux
* Sysmon

---

# What I Learned

* How to collect Windows logs
* How to search logs using SPL
* How to find suspicious activities
* How to investigate security events
* How to create dashboards
* Basic MITRE ATT&CK mapping

---

# Project Sections

## Log Collection

Collected Windows logs and Sysmon logs in Splunk.

## SPL Queries

Created different SPL queries to search and analyze logs.

Examples:

* Failed Login
* Successful Login
* PowerShell Activity
* CMD Activity
* Process Creation

## Detection

Created detections for suspicious activities like:

* Encoded PowerShell
* Certutil
* MSHTA
* Rundll32
* Regsvr32

## Threat Hunting

Used SPL queries to manually search for suspicious events.

## Incident Investigation

Investigated alerts by checking logs and finding the root cause.

## Dashboards

Created different dashboards to monitor security events.

Examples:

* Authentication Dashboard
* Malware Activity Dashboard
* Network Dashboard

## MITRE ATT&CK Mapping

Mapped some detections to the MITRE ATT&CK framework.
