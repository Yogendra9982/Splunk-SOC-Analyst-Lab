# SPL Queries

## Overview

This section contains the SPL (Search Processing Language) queries used in this project.

SPL queries are used to search, filter, and analyze logs collected in Splunk. These queries help identify suspicious activities and investigate security events.

---

# Purpose

The main purpose of these queries is to:

* Search Windows Event Logs
* Monitor user activity
* Detect suspicious processes
* Analyze security events
* Investigate incidents

---

# Query Categories

The queries in this project are organized into the following categories:

* Authentication
* Process Activity
* PowerShell Activity
* Command Prompt Activity
* Network Activity
* Malware Detection
* Sysmon Events

---

# Example Queries

Some of the SPL queries included in this project are:

* Successful Login Detection
* Failed Login Detection
* Process Creation Detection
* PowerShell Detection
* Encoded PowerShell Detection
* CMD Activity Detection
* Certutil Detection
* MSHTA Detection
* Rundll32 Detection
* Regsvr32 Detection
* Network Connection Monitoring
