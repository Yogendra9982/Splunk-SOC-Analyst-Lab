# Threat Hunting

## Overview

This section contains the threat hunting activities performed in this project.

Threat hunting is the process of searching for suspicious activities in the collected logs without waiting for an alert.

---

# Purpose

The main purpose of threat hunting is to:

* Find suspicious user activity
* Detect unusual processes
* Monitor network activity
* Identify Indicators of Compromise (IOCs)
* Investigate possible threats

---

# Hunting Activities

The following activities were performed:

* User Activity Analysis
* Process Investigation
* Network Connection Analysis
* PowerShell Investigation
* IOC Search

---

# Tools Used

* Splunk Enterprise
* Windows Event Logs
* Sysmon
* SPL Queries

---

# Result

Threat hunting helped identify suspicious activities and improve incident investigation skills using Splunk.
